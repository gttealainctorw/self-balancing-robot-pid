# CAD source

`base-deck.stl`, `mid-deck.stl` and `upper-deck.stl` are unmodified copies of the files in the `models/` folder of
[adoodevv/self_balancing_robot](https://github.com/adoodevv/self_balancing_robot). GitHub reports that repository's
license as MIT; see the `LICENSE` file there for the copyright notice and terms, which apply to these three files.

`tools/build_twin.py` reads them to generate `../robot.bin`, the mesh of the digital twin.
